# Mortgage calculator V1: Test scenarios

Each row is one test. The **Test** name is also the test name in the code. Money is exact to the cent. For `calc/payment` the input is written `loan EUR, rate %, months`. For `calc/validate` the input is the text as typed, `loan, rate, years`.

Error messages (from FR3): `Enter a number`, `Use at most 2 decimals`, `Term must be a whole number`, `Loan amount must be between 1,000 and 10,000,000 €`, `Rate must be between 0 and 25 %`, `Term must be between 1 and 40 years`.

## Sources of expected values

| Code | Source                                                                                                                                                                                          |
| ---- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| S1   | `docs/v1/reference-values.py`: exact rational arithmetic (Python `Fraction`, no floating point), annuity formula, rounded half up, FR2 totals rules. Run `python3 docs/v1/reference-values.py`. |
| S2   | The same script simulates the balance month by month with the exact payment. It ends at exactly 0 for every case, which confirms the annuity formula (not the rounding).                        |
| S3   | Written by hand from the rule or example in `01-functional.md`.                                                                                                                                 |
| S4   | Recomputed by an independent reviewer with no access to the script (see `04-review.md`).                                                                                                        |
| S5   | Exact tie cases checked with Python `Fraction` in the same script (no floating point).                                                                                                          |

## End-to-end tests: the real form in jsdom (all requirements)

"No result" means `#result` has the `hidden` attribute. "No error" means the slot text is empty.
