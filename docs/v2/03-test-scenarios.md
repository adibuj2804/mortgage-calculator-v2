# Mortgage calculator V2: Test scenarios

Each row is one test. The **Test** name is also the test name in the code (in Python the name is `test_` plus the scenario name with every `-` and `.` replaced by `_`). Money in the API is whole cents. Random tests use the fixed seed `20261022` so a failure can be reproduced. In the column "Verifies", `FRn` is a requirement, `goal n` is a goal of `05-plan.md`, `contract` is the API contract of `02-architecture.md`, and `module n contract` is the interface of a module in `02-architecture.md`. All tests run in CI except the one marked integration, which needs a real Supabase project and is run by hand.
